# proxi_cure
**Proxicure** is a web application developed during the **Youth Data Hack (August 2023 - October 2023)**. Its primary purpose is to assist users in locating nearby pharmacies that stock the medicines they require, streamlining the process of finding essential drugs. The project addresses a common challenge by simplifying how people search for pharmacies with specific medications, reducing the need for manual effort and long-distance travel.

The core functionality of Proxicure relies on **machine learning algorithms** to calculate the shortest path to the nearest pharmacy. By integrating geolocation services and optimizing search results, the application provides users with quick, accurate information. This intelligent solution improves accessibility to pharmacies and enhances convenience for users seeking timely access to medical supplies.

Proxicure exemplifies a practical application of technology in healthcare, emphasizing efficiency and user-friendliness.
